# 实验 07 哈希表的创建与查找（2 学时）

## 1. 实验题目

针对某个数值序列，设计一个哈希表，完成相应的建表和查表顺序。  
哈希函数用**除留余数法**构造，用**线性探测再散列**的方法处理哈希地址冲突。

---

## 2. 需求分析

本演示程序用 VC 编写，针对给定的数列：  
**{23, 5, 17, 12, 26, 31, 13, 4, 6}**，完成哈希表的构造。  
具体哈希函数采用**除留余数法**，并用**线性探测再散列**的方法处理哈希地址冲突。

- 表长：13
- 哈希函数：  
  \[
  H(key) = key \mod 13
  \]

### 功能要求：

1. 能根据给定值进行查询，判断该值在哈希表中是否存在：
   - 若存在，输出相应的地址；
   - 若不存在，输出“不存在”。
2. 能输出哈希表中的全部内容（若某地址为空，则不输出）。
3. 能输出该表的**平均查找长度 ASL**（假定每个元素被查找的概率相等）。

---

## 3. 概要设计

### 数据结构定义：

```c
typedef struct Elem {
    int key;           // 元素的值
    int compareTimes;  // 查找到该元素需要比较的次数
    int flag;          // 标识该位置是否已存有数据
} Elem;

typedef struct HashList {
    Elem *base;
    int length;
} HashList;
```

### 函数原型：

- `void CreateHashList(HashList &HL);` // 建立哈希表
- `void PrintHashList(HashList HL);` // 显示哈希表
- `void IndexHashList(HashList HL);` // 查找
- `void CalcuASL(HashList H);` // 计算平均查找长度 ASL
- `void main();` // 主函数

---

## 4. 详细设计

```c
void main() {
    HashList H;
    CreateHashList(H);
    PrintHashList(H);
    CalcuASL(H);
    IndexHashList(H);
}
```

## 6. 使用说明

程序名：`hash_tablet.exe`  
执行后界面如下：

```
========================
1. 显示哈希表
2. 查找
3. 退出
SELECT:
```

- 在 `SELECT:` 后输入数字选择功能。
- 必须先插入足够多的元素，才能进行其他操作。
- 每次执行功能后，会显示执行结果（正确或错误）以及当前哈希表内容。

### 功能选项：

- **选择 1**：显示哈希表
- **选择 2**：提示输入需要查找的关键字
- **选择 3**：提示输入要删除元素的位置，执行成功后返回该元素的值
- **选择 4**：退出程序
